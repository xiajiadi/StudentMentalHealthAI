# Database Technical Decision V1

Project: StudentMentalHealthAI  
Module: Database Persistence Layer  
Version: 1.0  
Status: PROVISIONALLY_FROZEN  
Date: 2026-09-05  
Depends: Root Contract v0.1.0 FROZEN  
Owner: Project Technical Lead

This document freezes the Round 1 engineering baseline. It does not freeze
clinical meaning, legal retention periods, research population, or production
deployment choices. The database stores supplied states and provenance; it
does not interpret psychological risk or make authorization decisions.

## Evidence used

- MySQL 8.4 LTS release model, character sets, foreign keys, JSON, InnoDB
  encryption, and backup guidance were checked against the [Oracle MySQL 8.4
  manual](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/mysql-releases.html)
  and the [MySQL 8.4 Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/).
- SQLAlchemy 2.0.52 was confirmed in the current [SQLAlchemy 2.0
  documentation](https://docs.sqlalchemy.org/en/20/). The async MySQL dialect
  and `aiomysql` connection form were checked in the [MySQL dialect
  documentation](https://docs.sqlalchemy.org/en/20/dialects/mysql.html).
- Alembic 1.19.2 documentation, async environment guidance, autogenerate and
  migration review practices were checked in the [Alembic
  documentation](https://alembic.sqlalchemy.org/en/latest/).
- Airflow's metadata database guidance was used as a migration-process
  reference only; its schema is not copied. In particular, migration scripts
  must not import live ORM classes. See [Airflow metadata database
  updates](https://github.com/apache/airflow/blob/main/contributing-docs/14_metadata_database_updates.rst).
- Privacy controls were mapped to the official [PIPL text](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm).
- Database, cryptographic storage, and key-management controls were compared
  with the [OWASP Database Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Database_Security_Cheat_Sheet.html),
  [OWASP Cryptographic Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html),
  and [OWASP Key Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Key_Management_Cheat_Sheet.html).
- Fernet and `MultiFernet` behavior was checked in the [pyca/cryptography
  documentation](https://cryptography.io/en/latest/fernet/).

### Non-breaking connection clarification

The application MySQL connection session timezone MUST be explicitly set to
`+00:00`. This makes the session baseline agree with D-19 and D-20 for
server-side timestamp expressions and runtime observability; it does not alter
the frozen root contract, the `DATETIME(6)` schema, or the application-owned
UTC-naive timestamp representation.

## Implementation consequences

- The schema has 19 domain tables. The Alembic version table is maintained by
  Alembic and is not a domain table.
- `accounts` contains only authentication identity and a password hash. The
  `subjects` table contains a pseudonymous reference and lifecycle provenance;
  it contains no name, student number, phone, address, or psychological field.
- Sensitive payload columns are nullable so an explicit synthetic purge can
  remove ciphertext and its key metadata while retaining safe operational
  history where appropriate.
- `support_evidence` stores citation references only. It does not copy raw RAG
  chunks.
- The database stores a supplied `SafetyAction`; it never derives
  `CRISIS_ROUTE`, `REVIEW_REQUIRED`, or a clinical label.
- `SqlAlchemyUnitOfWork` owns a per-use-case `AsyncSession`, commit, rollback,
  and close. Domain repositories never commit independently.
- `migrations/versions/20260905_0001_initial_database_schema.py` is a reviewed
  static migration and does not import the ORM models.

## Deferred or approval-gated items

Production KMS/Vault/HSM, production TLS certificates, encrypted real-data
backup storage, PITR, replication/HA, final retention duration, real guardian
consent semantics, ethics approval, clinical validation, and Backend composition
wiring remain outside this Round 1 freeze. None is silently represented as
complete by the schema.
