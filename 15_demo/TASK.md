# 15_demo：可重复演示与备份路径

## 职责

- 设计从测评到报告的最小可重复演示；
- 准备普通、关注、边界和高风险合成案例；
- 展示检索来源、模型/Prompt 版本和人工复核状态；
- 准备模型或依赖不可用时的安全降级和备份素材；
- 确保演示脚本与真实已实现能力一致。

## 输入

- Backend、Frontend、CAT、RAG、Runtime、Safety 的已验证输出；
- Evaluation 的合成 fixture 和结果；
- Deployment 的启动方案；
- 负责人批准的演示叙事和产品边界。

## 输出

- Demo runbook、合成数据和清理步骤；
- 普通案例完整链路；
- 高风险案例熔断/人工复核链路；
- 引用、版本和审计信息展示清单；
- 本地录屏、静态截图或其他明确标注的备份素材。

## 禁止事项

- 不使用真实学生数据、姓名、学号、联系方式或原始回答；
- 不伪造模型运行、检索命中、专家评价或研究效果；
- 不把概念图、Mock 数据或静态备份称为实时系统结果；
- 不为了演示绕过安全规则、权限或人工审核；
- 不展示未批准知识、虚构引用或未验证的部署能力。

## 接口

- 使用 api.v1 完成调用，不直接调用内部数据库或模型；
- 案例输入/输出符合 assessment.v1、knowledge.v1、generation.v1；
- 演示日志使用 request_id、trace_id 和合成业务 ID；
- 备份素材标注生成时间、版本、是否实时和适用范围；
- 失败时进入清晰的安全状态，而不是静默显示旧结果。

## 验收标准

- 新环境按 Deployment 文档可以复现演示；
- 普通案例能展示测评、检索、生成、引用和报告；
- high/crisis 案例能展示阻断和人工复核，不自动发布个性化建议；
- 模型、数据库或向量库不可用时有可解释提示和备份方案；
- 全程只使用合成数据；
- Demo 脚本逐项对应实际验证证据和已知限制。

## 交付物

- Demo runbook 和讲解脚本；
- 合成案例包；
- 普通/边界/高风险演示记录；
- 备份素材及真实性标注；
- 演示前检查表和现场故障处理表。
