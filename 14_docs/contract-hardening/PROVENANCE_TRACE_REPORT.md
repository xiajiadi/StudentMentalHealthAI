## Machine evidence

`evidence/provenance-machine-evidence.json` was generated by
`12_evaluation/scripts/provenance_contract_probe.py` against the in-process
FastAPI application using synthetic fixtures only.

- Normal support returned HTTP 202, `generation_status=EXECUTED`, and
  `candidate_source=CONTROLLED_SYNTHETIC`.
- Two citations were returned. The first retained chunk identity, document
  identity, rank, source version, and source hash.
- The report readback returned a citation list byte-equivalent to the support
  response and retained `generation_status=EXECUTED`.
- The crisis route returned HTTP 202 with `generation_status=NOT_RUN`,
  `candidate_source=NOT_RUN`, and null model, model-version, and runtime-version
  fields.

## Safety and provenance boundary

The frozen `generation.v1` schema was not changed. Execution-state metadata is
candidate projection data. A model candidate that is actually produced before
Safety blocks content retains its execution identity and is labelled
`CONTROLLED_SYNTHETIC` when the returned content is a controlled fixture; a
crisis/no-call path never receives a fabricated model identity.
