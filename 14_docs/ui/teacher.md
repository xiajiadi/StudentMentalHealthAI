# 教师表面

## 目标

让教师快速了解班级支持流程、定位需要关注的合成案例，并进入学生详情进行教育支持准备。教师看到的是受控摘要，不是诊断结论。

## 概览 `/teacher/overview`

信息层级：页面范围说明 → 合成 KPI 摘要 → 完成 / 支持流程趋势 → 待关注工作流 → 学生入口。

KPI 只表达流程事实，例如已完成数量、待确认数量和需要查看的记录；不使用临床 cut-off、心理诊断或风险概率。趋势图必须带文字摘要，并标明“合成演示”。

## 学生列表 `/teacher/students`

支持按姓名或合成标识搜索；列表显示状态、最近记录时间、关注动作和进入详情的链接。移动端改为堆叠行，不强迫用户在 375px 阅读宽表。

## 学生详情 `/teacher/students/:id`

内容顺序：学生身份摘要 → 最近测评 → 维度结构 → 教育支持摘要 → 观察 / 对话 / 课堂支持建议 → 依据与后续时间线。

当案例需要人工确认时，详情页明确显示“普通生成已暂停，等待人工复核”，不提供普通生成按钮。教师不能在前端改变 Safety 结论或直接调用模型。

## 密度与可访问性

教师概览 Design Dials 为 Variance 3 / Motion 2 / Density 7；详情为 3 / 2 / 6。桌面使用固定侧栏和内容优先布局；图表、表格、筛选器均需有标题、文字替代、键盘焦点和空 / 错误状态。
