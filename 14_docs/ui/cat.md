# CAT Focus Mode

## 目标

提供安静、专注、可恢复的测评参与界面。前端只负责展示后端返回的题目和会话状态，不实现 CAT 算法、theta / SE、IRT 或停止规则。

## 布局

- 独立 Focus Layout，无教师 / 复核侧栏、AI 助手、风险徽章、倒计时、统计面板或游戏化元素；
- 一次只显示一题、选项、当前记录进度和明确的保存 / 完成动作；
- RadioGroup 支持键盘方向键和 Tab；选择不会自动提交；
- 离开 / 暂停需要确认；提交失败提供可恢复重试；会话不可用显示原因和重新准备动作。

## 自适应措辞

页面使用“第 N 题 · 测评进行中”和“已记录 N 项”等事实性措辞。没有后端明确返回的总题数时，不显示“共 X 题”或承诺固定总量；后端返回 `can_complete` 后，才展示可以结束流程的动作。

## 状态

覆盖题目加载、选项选择、保存中、可完成、保存失败、会话不可用和完成后跳转。不存在自动提交；按钮禁用必须有可理解的状态反馈。

## 边界

CAT fixture 是工程演示数据，不代表心理测量效度；CAT 页面不做风险判断，不向学生暴露内部工程参数。
