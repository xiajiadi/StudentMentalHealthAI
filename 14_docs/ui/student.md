# 学生表面

## 目标

帮助学生理解当前支持流程和下一步行动。学生页面采用安静、低密度、意义优先的结构；它不是 KPI 仪表盘，也不是临床报告。

## 学生首页 `/student/home`

首屏顺序：

1. 页面标题和一句范围说明；
2. 当前建议的下一步（开始测评或查看最近结果）；
3. 最近一次结果的简短状态；
4. 可获得的支持入口和简短说明；
5. 最近记录。

加载、首次为空、服务失败分别提供骨架、开始入口和重试动作。空态不暗示学生存在问题，文案只说明如何开始或如何获取支持。

## 学生可见数据

- 当前流程状态、题目进度、已完成记录；
- 经整理的含义、一个可完成的小行动和已审核依据；
- 明确标注为“合成演示”的结构化图表。

学生不可见：theta、SE、IRT、模型评分、向量相似度、开发 trace、原始风险标签、未经审核的生成文本、内部阈值和分类器名称。

## 交互与响应式

- 主要动作保持单一、明确、可恢复；不使用游戏积分或倒计时。
- 375px 下内容单列，支持卡片和记录自然堆叠；长引用允许换行，不产生页面级横向滚动。
- 所有链接和按钮有可读名称、明显焦点和约 44px 的实际操作区域。
