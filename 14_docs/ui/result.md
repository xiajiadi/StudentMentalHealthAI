# 学生结果页

## 目标

让学生先理解结果能帮助整理什么，再看到有限的结构化信息、一个下一步行动和有序依据。页面不模拟临床报告。

## 固定顺序

### Meaning

先说明这份结果可以怎样帮助整理近期支持和下一步；避免把内部数字直接当成结论。

### Data

展示合成结构占位和可读的维度标签；图表标注“合成占位、非诊断”。不展示 theta、SE、IRT、模型评分、相似度或内部风险标签。

### Action

给出一个小而具体、可执行的教育支持行动；若结果内容不存在，不渲染空洞的行动按钮。

### Evidence

按 adapter 返回的引用顺序展示已审核依据，保留标题、机构、定位和摘录等实际存在的元数据。缺失字段保持缺失，不猜测页码、作者、日期或 URL。引用不可用时说明原因并提供返回 / 稍后查看的路径，不伪造来源。

## 状态与响应式

覆盖加载、引用不可用、部分元数据和完整结果。375px 下图表与文字摘要上下排列；引用内容自然换行；页面级不出现横向溢出。图表同时提供 `aria-label` 和文字摘要。
