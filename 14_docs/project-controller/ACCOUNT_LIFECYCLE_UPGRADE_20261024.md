## API 与使用说明

- 管理员在“账号管理 → 学生花名册”下载模板，填写学号、姓名、班级与可选年级。文件先经过服务端预览，再由管理员确认写入。
- 邀请、首登凭据和恢复凭据在受控页面内一次返回；页面不显示秘密明文，学生凭据可以加密下载。学校邮件与短信通道未配置，教职工邀请明确显示人工交付要求。
- 邀请、激活、改密、状态变更、教师核验与恢复审批都有审计记录；审计元数据不包含密码、一次性令牌或反馈正文。
- Lifecycle API 通过独立路由与 DTO 承载花名册预览/导入、账号摘要与状态、一次性凭据、教职工邀请、学生恢复工单及教职工恢复；不改变既有测评结果读取权限。
