## 功能与交互

学生主页通过“智能体”进入独立工作区，保留“首页”“我的测评”和“我的记录”。学生从智能体页进入现有教育支持、测评、校内支持和已发布反馈。其他三个角色的工作区保留原业务页入口。四端共享原品牌、Vue、Reka UI 和设计令牌。

工作区前端只渲染 `workspace_agent.v1` 结构化类型。工作项来自现有角色限定服务。输入只匹配有限任务，未识别内容不转发到模型，也不写工作区会话。学生的已知学习主题进入原教育支持页供本人发送，依次经过原有输入安全、检索、生成和输出安全。已有教育支持公开演示继续使用配置的 DeepSeek 服务。

管理员可以用“新建班级 班级编号”预览创建操作。确认令牌绑定学校、角色及会话，期限五分钟。使用后端现有幂等记录及单事务审计。工作区增量无需修改数据库结构。

参考了 Codex 的任务与审批交互、Claude Code 的会话恢复，以及 WorkBuddy 的任务入口与敏感操作确认。PsyNova 业务写入继续通过受限的后端工具，不开放任意脚本能力。[Codex 应用功能](https://developers.openai.com/codex/app/features) [Claude Code 工作流](https://code.claude.com/docs/en/common-workflows) [WorkBuddy 任务栏](https://www.codebuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)

## 安全、速度与限制

现网发布前抽取的 13 次完整生成中，输出安全检查中位数 19.23 秒，最长 46.47 秒。实测有来源请求 19.27 秒、返回两条引用，缺乏证据的请求 4.09 秒并弃答。源配置同步了工作区对话网关的等待预算，涉及三次安全检查和一次推理。此值是慢请求等待上限，无法直接缩短推理时间。[Nginx 代理等待配置](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_read_timeout)

ECS 为 2 vCPU，核实未提供可用的 NVIDIA 设备。涉及学生心理隐私的私有自由对话、辅助访谈、正式量表结果解读与个性化干预仍需独立验证。工程检查不能代替心理专业审核或真实学校使用审批。[世卫组织 AI 健康治理指引](https://www.who.int/publications/b/70584) [未成年人网络保护条例](https://app.www.gov.cn/govdata/gov/202310/24/508651/article.html) [生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)
