# 13_deployment：本地运行与部署

## 职责

- 提供本地开发、测试、演示和恢复的启动方案；
- 管理环境变量、依赖、模型注册和服务健康检查；
- 说明 CPU/GPU、模型、Embedding、数据库和向量库要求；
- 确保失败可诊断、配置可替换、数据可清理；
- 为演示和后续研究准备可复现的部署记录。

## 输入

- Backend、Frontend、Database、LLM Runtime 的运行需求；
- 模型/Embedding/向量库注册信息；
- 合成数据和 Demo 流程；
- 用户全局的 D 盘优先与本地优先约束。

## 输出

- 启动、停止、健康检查和排障说明；
- 环境变量样例和配置校验；
- 本地依赖/模型清单及版本；
- 数据初始化、备份和清理流程；
- 可供 Demo 使用的运行包或启动脚本。

## 禁止事项

- 不把密钥、真实数据或本机绝对路径写进仓库；
- 不默认把模型、缓存、依赖堆到 C 盘系统目录；
- 不隐式连接外部云服务或把云服务当静默回退；
- 不宣称未验证的平台、GPU、模型或安装器支持；
- 不把“能在开发机启动”描述为完整发布验收。

## 接口

- 读取统一配置和模型注册表；
- 提供 service health -> api.v1 health；
- 与 Backend、Database、Runtime 的启动顺序和依赖检查对齐；
- 为不同环境提供明确 profile，不改变 Contract；
- 将路径、缓存、端口和资源上限设为可配置项。

## 验收标准

- 按文档可在目标本地环境启动最小纵向链路；
- 缺模型、数据库、向量库、配置或端口占用时给出可解释错误；
- 合成数据初始化/清理可重复；
- 本地缓存和模型路径可配置且默认遵守 D 盘优先；
- 健康检查能区分服务可用、依赖降级和不可用；
- 记录实际验证的平台、硬件和未覆盖范围。

## 交付物

- 本地启动和排障文档；
- 配置样例；
- 服务健康检查；
- 依赖/模型/缓存清单；
- 备份、清理和演示恢复方案。
