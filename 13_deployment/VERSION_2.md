# PsyNova 2.0 版本记录

## 公网体验

通过 [PsyNova 公网入口](https://psynova.top/login) 注册。服务为每个体验账号建立隔离的合成学校，支持切换学校管理员、心理教师、普通教师和学生。部署的 Vue 资源与服务器文件逐项校验，源码记录覆盖后台、数据库、接口契约、测评接入、Prompt、CAT、RAG、模型运行时与安全服务。

- [线上文件清单](online-baseline-v2.json)
- [公网部署说明](PUBLIC_DEMO.md)

公网发布资产中的 Vue ZIP 是前端静态快照。公网数据库、会话、验证码配置和模型服务凭据由受控部署环境管理。

公网使用独立运行的 CAT 工作台组件。如果另建环境，需要为它单独准备服务。版本记录校验的是列出的应用文件和静态页面。

## 学校本地

学校版与体验版共用产品基线。本地安装目标是独立业务库，启用前由管理员配置学校、初始账号和权限，由学校内网的 HTTPS 地址提供服务。学生、班级、测评、作答、会话和学校自有资料从空库开始。

现有 [Vue Windows 核心候选](VUE_OFFLINE_CORE.md) 用于合成环境验收。学校本地完整版以发布条目中的受验证安装资产为准。学校上线前还需核对本地推理硬件、数据审批和备份恢复。

## 维护入口

原版 Vue 源码在 `10_frontend/`。历史 React 开发保留在 `10_frontend_react/`，适合按历史分支回看。产品介绍由 `site/` 生成到 `gh-pages` 分支，站点图片取自合成学校实际界面。
